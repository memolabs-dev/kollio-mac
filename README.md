# Kollio

A living visual document that humans and AI build, question and evolve together.

The canvas is the application. A `.kollio` document is the product model. An
intelligence source proposes a patch; it never regenerates the world.

## What runs today

| Piece | State |
|---|---|
| `packages/KollioCore` | Domain, document format, commands, decisions, proposals, request-bound snapshot, validation. Swift and Foundation only. |
| `packages/KollioApp` | macOS app: entry point, canvas, camera, contextual actions, ghost branches, undo, save, FR/EN. |
| `services/KollioServer` | Vapor API. Offline demo provider by default, Groq provider disabled until a key exists. |

## Start here

Launch with nothing stored and the app asks one question: *What are we working on?* Type a context,
press `Cmd+Enter`, and it becomes a real object on the canvas, saved before any intelligence is
requested. The source proposes a branch beside it; you keep it or you do not. Nothing you typed is
ever replaced by a summary.

Sarah is a demo, reachable from `File` → `Open Demo` (`Cmd+Shift+D`). It is never what a launch falls
back to.

## Run it

```bash
# 1. everything, offline (the app never needs the backend)
./scripts/run-app.sh            # builds and opens Kollio.app
./scripts/run-app.sh --shot     # same, plus an isolated Kollio-window screenshot (macOS Screen Recording permission needed)

# 2. every test suite
./scripts/test-all.sh

# 3. everything, including the Xcode app target
./scripts/verify.sh
```

## In Xcode

Open `Kollio.xcworkspace`. It holds the three packages **and** `Kollio.xcodeproj`, a thin
app target that exists only so Cmd+R, the debugger, breakpoints and the Info.plist editor work.

| Where | What it is |
|---|---|
| `Kollio.xcodeproj` | generated by `scripts/sync-xcodeproj.py`, never edited by hand |
| `packages/KollioCore` | the domain, the single source of truth |
| `packages/KollioApp` | the same app sources, plus the tests |
| `services/KollioServer` | the backend |

The app target compiles the same sources as the `KollioApp` package. That duplication is deliberate
and is the only one in the repository. After adding or removing an app source, regenerate:

```bash
./scripts/sync-xcodeproj.py
```

Three ways to work on the document:

1. **Offline, demo engine.** Open the app. Nothing leaves the machine.
2. **Local backend.** `KOLLIO_API_TOKEN=$(openssl rand -hex 32) swift run --package-path services/KollioServer kollio-server`,
   then point the client at it with `KOLLIO_SERVICE=server`. Without `KOLLIO_GROQ_API_KEY` the server
   also runs on the demo engine.
3. **Remote model.** Set `KOLLIO_GROQ_API_KEY` and restart the server. Never in the app bundle, never in
   a `.kollio` file, never in Git. **Never called with a real key yet**: the wire contract is tested
   with a mock, which says nothing about a live model's output.

The client is told which source is in use by the environment, and says so in the status line. It does
not fall back silently. See `docs/CONTINUE.md` for the exact commands.

Keyboard: `Cmd+0` fit, `Cmd+1` actual size, `Cmd+Z` undo, `Cmd+Shift+Z` redo, `Cmd+S` save, `Cmd+Enter`
submit in a composer, `Escape` returns to the calm state.

## The first loop

```
Sarah, one context and two directions
  → select a direction
  → Explore
  → the proposal appears where it would enter the graph
  → Keep            (one transaction, undone as one action)
  → Set aside       (a durable reason, the branch collapses and stays inspectable)
  → Reopen          (the same objects, relationships and positions come back)
  → save, quit, reopen
```

## Visual review

The optional `--shot` path uses ScreenCaptureKit with `desktopIndependentWindow` and requires exactly one visible window whose bundle ID is `dev.kollio.app`. It **never records the whole desktop**, never crops another app from display coordinates, and exits nonzero without an image when macOS privacy consent is missing. Grant Screen Recording permission to the terminal or launcher in System Settings and retry. Always inspect the captured pixels before citing them as evidence; screenshot success is not external-user acceptance.


`KOLLIO_REVIEW=<state> ./scripts/run-app.sh` opens the app in a given state, so each step of the
vertical slice can be captured in a screenshot: `explore`, `kept`, `setaside`, `reopened`.
