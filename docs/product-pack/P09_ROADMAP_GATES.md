# P09 — Roadmap & Gates

Roadmap par preuves, pas par dates.

## G0 — Real entry + local intelligence
Entrée réelle, persistance avant inference, Apple adapter, proposition valide, no server requirement, keep/undo/save/reopen.

## G1 — Useful native intelligence + interaction confidence
FR/EN, pointer/trackpad, usefulness, latency, gestures, visual hierarchy.

## G2 — Distributable SOLO beta
Recovery, keyboard, accessibility, relationship selection, 100/200 workload, signing, visual QA.

## G2.5 — Apple system intelligence
Document entity, thought entity, open/find/add thought, safe indexing, App Intents tests, IntentLane dogfood.

## G3 — Organization pilot
Tenancy, sharing, roles, conflicts, policy, PostgreSQL where justified, runbooks.

## G4 — Enterprise readiness
Federation, policy enforcement, SLOs, incident/restore drills.

## G5 — Interoperability
Read-only web viewer d’abord, import/export ensuite, ecosystem seulement après gates dédiés.

## Apple phases

A evaluations  
B SOLO human journey  
C entities/intents/indexing  
D view annotations when readable  
E retrieval  
F image + OCR  
G profiles/PCC if justified  
H Core AI  
I sync/transfer/ownership TEAM

## Kill criteria

Stop/différer si :

- aucun journey nommé n’est amélioré ;
- un invariant doit être affaibli ;
- le chat est objectivement meilleur ;
- rien n’est mesurable ;
- une UI permanente apparaît pour résoudre un problème local ;
- la complexité provider augmente avant preuve du produit local.
