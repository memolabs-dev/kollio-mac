# P05 — Journeys & Interaction Model

## State machine canonique

`Rest → Hover → Select → Act → Compose/Explore → Propose → Decide → Settle`

## J1 — Start from nothing

Ouverture → contexte réel → persistance → intelligence optionnelle.

Le document doit être valide même si le modèle échoue juste après.

## J2 — Explore

Sélection → action locale → snapshot immutable → génération → ghost branch → Keep / Set aside.

## J3 — Add manually

Sélection → Add → composer local → submit → objet + relation atomiques.

Idéal : `control → composer → node → settled branch`.

## J4 — Set aside / reopen

Écarter → raison → collapse durable → inspecter → reopen restaure les mêmes objets/relations/positions.

## J5 — Attach source

Drop ou action → prévisualiser la conséquence → attacher → afficher extraction → ne rien envoyer implicitement à un modèle.

## J6 — Peek source

Sélection → preview/reader temporaire → retour exact au canvas.

## J7 — Compare

Sélection multiple → comparaison → retour avec caméra et sélection préservées.

## J8 — Save / quit / reopen

Le monde revient identique sémantiquement. Rien ne « redevient nouveau ».

## J9 — Provider unavailable

Échec explicite → aucun fallback silencieux → édition manuelle toujours possible.

## Escape ladder

`editing → attribution → proposal/selection → normal document`

Une pression retire une couche, pas tout le contexte.

## World-space

Nodes, frames, relations, ghosts.

## Screen-space

Actions contextuelles, controls de composer, décision proposal, command palette.

Les instruments restent lisibles indépendamment du zoom.
