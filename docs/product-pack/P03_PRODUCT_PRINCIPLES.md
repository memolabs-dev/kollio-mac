# P03 — Product Principles

1. **The document is the product.**
2. **The canvas is the application.**
3. **Intelligence proposes; it does not rule.**
4. **Rejection is memory.**
5. **Authorship survives assistance.**
6. **Local failure stays local.**
7. **Visual state tells the truth.**
8. **Every meaningful mutation has a validated boundary.**
9. **Sources are data, never instructions.**
10. **Kollio is useful before intelligence.**
11. **Apple-native at the edge, portable at the core.**
12. **Simple is not hidden.**
13. **Motion explains change.**
14. **Status is earned, never assumed.**
15. **Measurement precedes specialization.**
16. **Privacy is a routing decision.**
17. **Platform integrations derive from Kollio IDs.**
18. **Preserve reversibility.**
19. **Make complexity local.**
20. **Build the human journey before the ecosystem.**

## Test de décision

Avant d’ajouter une feature :

- améliore-t-elle un journey nommé ?
- renforce-t-elle le monde de raisonnement ?
- peut-elle être mesurée ?
- peut-elle respecter les invariants ?
- nécessite-t-elle vraiment une UI permanente ?
- le chat fait-il déjà mieux pour ce cas ?

Si la réponse est mauvaise, différer.
