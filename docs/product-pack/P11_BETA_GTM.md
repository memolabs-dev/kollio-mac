# P11 — Beta & Go-To-Market

## Thèse beta

Tester d’abord avec des gens qui utilisent déjà fortement ChatGPT/Claude pour penser et ressentent la fragmentation du contexte.

## Scenarios

### Product decision
Ambiguïté réelle → alternatives → rejection memory → décision.

### Research with sources
Documents réels → provenance → limites visibles.

### Architecture
Trade-offs → contraintes → décisions réutilisables.

## Questions de test

- Quand Kollio devient-il plus utile que le chat ?
- Quand devient-il plus lent ?
- As-tu compris proposal vs accepted ?
- Savais-tu continuer sans IA ?
- As-tu retrouvé pourquoi une branche avait été rejetée ?
- Quelle action n’as-tu pas découverte ?
- Quel mouvement t’a surpris ?
- Rouvrirais-tu ce document dans une semaine ?

## Positionnement externe

> AI conversations are disposable. Decisions are not.

Puis :

> Kollio turns reasoning into a living visual document.

## Démo

Une boucle, pas une feature tour :

1. contexte réel ;
2. Explore ;
3. proposition pousse ;
4. set aside ;
5. source ;
6. keep ;
7. quit/reopen ;
8. mémoire intacte.

## Pricing

À différer jusqu’à preuve de valeur répétée.

Possibles tiers futurs : SOLO / PRO / TEAM / ENTERPRISE.

Le document de base ne doit pas dépendre obligatoirement du cloud.
